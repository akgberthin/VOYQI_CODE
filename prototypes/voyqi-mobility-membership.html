Vehicle Swap & Request Queue
MOB-006 · Requesting a swap stages a fleet-svc transfer PROPOSED, never dispatched — the same human-dispatch requirement whether the transfer originated from a member request or an AI recommendation elsewhere on the platform.
Upgrade Intelligence
MOB-011 · Detecting a pattern and offering an upgrade case never touches billing — fully autonomous. Actually enacting the upgrade (which raises what the member pays) is always a separate, member-confirmed acceptance; the agent that offers a case never accepts it on the member's behalf.

Deposit Holds
MOB-012 · $5,000–$25,000 holds for Luxury Plus / Performance Plus. Placement and full release are a fixed table lookup by class — deterministic policy, not a judgment call, so both execute autonomously. Capturing part of a deposit is the one genuine financial-risk judgment call and always requires human approval, regardless of amount or AI risk score.

Travel Declaration & Mobility Continuity
MOB-008 · "Your Mobility Travels With You" — a declared trip resolves the destination market's equivalent class via configured equivalency rules, falling back to the member's own class unchanged if no rule exists yet, so continuity never fails outright over a missing configuration.
